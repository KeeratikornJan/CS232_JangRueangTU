ระบบ Web Application สำหรับรับเรื่องร้องเรียนและแจ้งเหตุภายในมหาวิทยาลัยธรรมศาสตร์ รองรับผู้ใช้ 2 กลุ่ม คือ **ผู้ใช้ทั่วไป** และ **Admin**

---

## ภาพรวม AWS Architecture

ระบบทำงานบน Serverless Architecture ประกอบด้วย S3 (โฮสต์เว็บ + เก็บรูปภาพ), API Gateway, Lambda, DynamoDB, SNS (ส่ง Email), Cognito (Admin Auth — Phase 2) และ CloudWatch (Logging)

---

## วิธีการใช้งาน

### ผู้ใช้ทั่วไป

1. เลือกประเภท **ร้องเรียน** หรือ **แจ้งเหตุ** จาก Navbar
2. เลือกหมวดหมู่ที่ตรงกับปัญหา (สถานที่, บุคลากร, รถโดยสาร ฯลฯ)
3. กรอกข้อมูลส่วนตัว ได้แก่ ชื่อ-นามสกุล, อีเมล, เบอร์มือถือ, เลขบัตรประชาชน 13 หลัก
4. กรอกรายละเอียดเหตุการณ์ พร้อมระบุสถานที่และวัน-เวลา
5. แนบรูปภาพหลักฐาน (ถ้ามี) แล้วกดส่ง
6. ระบบจะส่ง **Email ยืนยัน** และแสดงหน้ายืนยันการส่งข้อมูล

### Admin

1. เข้าสู่ระบบที่หน้า Login ด้วยอีเมลและรหัสผ่าน
2. ดูภาพรวมเคสทั้งหมดได้ที่ **Dashboard** (กราฟและสถิติ)
3. จัดการเคสผ่านเมนู **ร้องเรียน** หรือ **แจ้งเหตุ** — ดูรายละเอียด, อัปเดตสถานะ, เพิ่มหมายเหตุ
4. ส่งต่อเคสไปยังหน่วยงานที่รับผิดชอบผ่านเมนู **ส่งต่อ**
5. ดูประวัติเคสที่ดำเนินการแล้วได้ที่เมนู **ประวัติ**
